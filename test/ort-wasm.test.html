Does the vendored engine start without cross-origin isolation?

Three rounds of an iOS bug were spent on the theory that it could not: first that WebKit refuses shared WebAssembly memory outside an isolated page, then that it refuses the 4 GB reservation emscripten's glue asks for. The device disproved both, one rebuild at a time.

This asks the question directly. Chromium without COOP/COEP reproduces the capability signature iOS reported — SharedArrayBuffer absent from the global scope, shared wasm memory granted anyway — so a pass here means the memory layer is not the fault, and the next theory has to be about something else.

Run it with and without isolation headers; both must pass. It needs no model and no network: the 21 MB binary under vendor/tts/ is the subject.
